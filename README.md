# 🌸 Azaleaporten

Ett gratis äventyr där barn övar **matematik, svenska och engelska**. Skapa en hjälte, kliv in genom porten och utforska Talbergen, Ordskogen och Västerön.

**Spela:** https://andrejohanssonlindh.github.io/azaleaporten/

- Allt sparas bara på den egna enheten. Inga konton, ingen spårning, inga kakor.
- Fungerar på dator, surfplatta och mobil, även offline när den är installerad som app.
- Installera: Safari → Dela → "Lägg till på hemskärmen", eller Chrome/Edge → "Installera app".

Under utveckling: Tidstornet (klockan) är först ut.

## Utveckling

```sh
npm install
npm run dev     # http://localhost:5173/azaleaporten/
npm test
npm run e2e
```

Varje push till `main` testas, byggs och publiceras via GitHub Pages.
